# GI-only graphs

This folder contains the gait-initiation (GI) interval from the existing segmented-data export for every completed graph with a resolved GI label.

- `per trial/`: 748 GI-only PNG graphs, arranged by subject, recording and trial.
- `per trial/gi_plot_manifest.csv`: source information and duration for each GI graph.
- `per trial/unresolved_gi_manifest.csv`: 8 completed graphs for which the saved export contains only `UNKNOWN` or `UNRESOLVED`, with no GI interval to extract.

The GI boundaries and labels are provisional. `tempgraphs/` was not edited.
