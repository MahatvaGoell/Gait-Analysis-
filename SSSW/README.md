# SSSW sections

This folder contains 746 per-trial SSSW graphs, redrawn in the requested phase-band layout. Each graph shows only the saved SSSW interval, with `SSSW*` above the graph, exact start and end timestamps, and dashed vertical boundary lines.

All eight FMG channels, CoP, and vGRF are plotted from the saved segmented-data export. Each trace retains the matching full-trial baseline, gain, and vertical offset so the visible variation is comparable to its complete trial graph. `per trial/unresolved_sssw_manifest.csv` lists the 10 trials without a saved resolved SSSW label.
