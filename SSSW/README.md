# Clear SSSW sections

This folder contains 746 clear SSSW graphs. Every graph is rendered from the saved SSSW samples using the matching completed graph's recorded baseline, gain, and offset for all ten signals.

The resulting graph keeps the completed graph's vertical signal display while showing the SSSW time section clearly with a title, axes, time range, and legend. `per trial/unresolved_sssw_manifest.csv` lists 10 graphs without a resolved SSSW interval. `tempgraphs/` was not edited.
