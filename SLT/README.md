# Clear SLT sections

This folder contains 746 clear SLT graphs. Every graph is rendered from the saved SLT samples using the matching completed graph's recorded baseline, gain, and offset for all ten signals.

The resulting graph keeps the completed graph's vertical signal display while showing the SLT time section clearly with a title, axes, time range, and legend. `per trial/unresolved_slt_manifest.csv` lists 10 graphs without a resolved SLT interval. `tempgraphs/` was not edited.
