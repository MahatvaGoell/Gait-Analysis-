# QS-only graphs

This folder contains a separate quiet-standing (QS) image for every current completed graph in `../tempgraphs/`.

- `per trial/`: 756 QS-only PNG graphs, arranged by subject, recording and trial.
- `per trial/qs_plot_manifest.csv`: the 729 graphs created directly from the original FMG and insole recordings.
- `per trial/segmented_data_qs_fallback_manifest.csv`: 27 graphs created from the existing segmented exports where the original trigger or sensor stream was incomplete.

The QS boundaries and labels are provisional. `tempgraphs/` was not edited.
