# Clear GT sections

This folder contains 746 labelled gait-termination (GT) graphs. Each graph uses the saved GT samples and the matching completed graph's recorded baseline, gain, and offset for all ten signals.

The title, phase label, subject, record, trial, limb, original elapsed-time range, axes, and signal legend are included in every graph. `per trial/unresolved_gt_manifest.csv` lists 10 graphs without a resolved GT interval. `tempgraphs/` was not edited.
