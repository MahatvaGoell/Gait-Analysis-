# Clear SSLW sections

This folder contains 746 labelled steady-state long-step walking (SSLW) graphs. Each graph uses the saved SSLW samples and the matching completed graph's recorded baseline, gain, and offset for all ten signals.

The title, phase label, subject, record, trial, limb, original elapsed-time range, axes, and signal legend are included in every graph. `per trial/unresolved_sslw_manifest.csv` lists 10 graphs without a resolved SSLW interval. `tempgraphs/` was not edited.
